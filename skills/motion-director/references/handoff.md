# Handing the trial to a full-film skill

The trial project is the start of the full film. Leave it so the full-film skill can continue without asking again.

## Write `handoff.md` in the project

```markdown
# Handoff
- Film type: launch film            (the type from the table below)
- Full film: Launch Video (project-to-launch)
- The point: <the one line the trial says>
- Material read: <files, URLs, rows>; everything on screen is in sources.md
- Look: <style>, palette <hex…> — from: <source>; type <font>
- Score: <bpm>, motif <notes> (in index.html, mo-score)
- What the full film adds: <the parts left out: other features, the structure, the type's own abilities>
```
